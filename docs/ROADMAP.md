# Product Roadmap

## Milestone 1: MVP Release (Current)
- Complete catalogue ingestion from upstream repository.
- Dynamic prompt variable builder with confidentiality pre-flight.
- Fictional scenario & blueprint generator.
- Indian legal overlays (BNS, BNSS, BSA, DPDPA, CPC, Companies Act).
- 5 comprehensive guided legal workflows.
- GitHub Pages static deployment.

## Milestone 2: Advanced Educational Tools
- Offline downloadable PDF reference guides.
- Expanded jurisdiction modules (state-specific High Court rules).
- Extended PEAS interactive case simulations.

## Milestone 3: Future Enterprise Scenarios (Non-MVP)
- Client-side document parser (in-browser WebAssembly).
- Organization custom playbook import.
